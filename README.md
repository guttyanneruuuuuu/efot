# Pocket Football ⚽

机でサッカー風 + eFootballライクな簡単操作の1vs1ブラウザサッカーゲーム。

## 特徴
- 📱 スマホ横画面に最適化
- 🤖 AI戦（3段階の難易度）
- 🌐 オンライン1vs1対戦（PeerJSによるP2P）
- 🎮 シンプル4操作: ジョイスティック / パス / シュート（パワー溜め）/ ディフェンス
- ⏱ 試合時間: 3分（前後半各1.5分）
- 🎨 トップダウン視点でわかりやすい

## プレイ
1. メニューから「AI戦」「オンライン対戦」を選ぶ
2. 左下スティックで選手を移動
3. 右下のボタン:
   - **P**: パス
   - **S**: シュート（押し続けでパワー溜め、離して発射）
   - **D**: 一番近い選手に切り替え＋タックル

## 技術
- Pure HTML5 Canvas + JavaScript（ライブラリ依存最小）
- PeerJSによるWebRTC P2P対戦
- GitHub Pagesでホスト

## ローカル実行
```
python3 -m http.server 8000
# ブラウザで http://localhost:8000
```
